# ONHOLD

参考 SingleSpark 的浅灰背景、左侧导航、白色圆角卡片和黑色胶囊按钮实现的三个页面，主菜单只有「首页」和「赔付领取」。

- `index.html`：6 个演示广告位、分类和排序、竞价替换、数据入口。
- `analytics.html`：参与者点击排行、7/30 天示例趋势、累计赔付金额与人数。
- `claim.html`：钱包入口、四步图片教程、验证字段说明。

运行 `npm run build`、`npm test`，然后 `npm run dev`。打开 http://localhost:4173（如端口占用可换一个端口）。无运行时依赖。

## 竞价与统计

前 24 小时不衰减，每满 24 小时价格减半，精确到 wei 且最低 1 wei。必须严格高于当前价才能替换。新广告从零累计点击，被替换广告及其历史点击保留在排行里。全部广告状态保存在浏览器本机，不会同步给其他用户；示例图表不含本机点击。

广告项目和赔付数字均为示例，不代表真实成交、访问人数或赔付。初始示例广告链接指向 example.com。用户演示竞价的地址必须为无内嵌凭证的 HTTPS 链接。

## 钱包和验证边界

钱包按钮调用浏览器注入钱包的账户授权接口并读取网络；不签署登录消息，不发起支付或领取交易。账户/网络变化会提示重新核验。未提供浏览器钱包时，图片指南仍可查看。

图中全部账号及凭证都是虚构示例。尚未接入验证服务或测试网合约，所以真实凭证输入框禁用，不收集、不发送凭证，也不模拟验证成功。

已在用户授权的浏览器中观察到 `/api/account/standing` 返回 `standing`、`banned_at`、`prev_plan_tier`、`banned_orgs[].uuid` 和 `has_active_org`。这是网站内部接口，尚未完成独立服务端复查实测。组织 UUID 不是个人用户 ID；prev_plan_tier 是此前套餐；响应不含完整封禁历史、订阅账单和续费信息。

正式开放赔付之前，需要固定目标的 HTTPS 服务端核验、钱包归属证明、防重放、组织去重、短时领取签名和合约验签。不要执行用户提交的 cURL，不接受任意验证 URL，不记录会话凭证；网络错误、验证码和 403 不能视为封禁。用户要求自动核验，不设置人工审核。

## 已验证

Node 测试覆盖精度、24 小时衰减边界、低价拒绝、历史保留、HTTPS 校验、转义、本机存储校验和图片引导导航。桌面浏览器手动检查竞价成功/失败、历史排行、图表切换、图片步骤、图片放大和快捷键切换。
